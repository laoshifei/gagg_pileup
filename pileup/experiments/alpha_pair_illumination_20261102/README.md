# 保持光子时谱的位置随机化对照

本实验检验上一轮共享微胞响应失配中的空间照明贡献。全部结果限于四对已暴露的历史光学母事件，使用真实事件身份分解信号；不作盲重建或新独立输运性能主张。

## 实际结果

2026-11-02完成11,520次位置干预数字化对照。在四对历史母事件上，强→弱8/40 ns的弱分量面积损失从15.74%/15.37%降至9.37%/9.18%，均匀化效应为6.36/6.19个百分点，配对描述性95%区间分别[5.82, 6.91]/[5.69, 6.65]。只打乱位置顺序而保留原空间密度，五种条件的效应区间均包含零；恢复关闭后三臂波形和电荷数组逐项相同。结果支持空间照明不均匀是当前模型偏差的重要来源，未证明它是唯一来源，也未验证新的能量重建算法。

仅八个已暴露光学母事件、四个母对；位置/数字化重复不增加独立输运样本数。均匀化后的弱分量抑制端点通过原有5个百分点的点估计门，不能推广成原始波形或全能区控制已通过。均匀化同时使强孤立脉冲面积增加约8%，单事件标定与共享恢复必须共同处理。本轮给定真实事件身份、时刻和用于诊断的输入光子，没有盲检出、能量拟合、漏检/误拆并或能谱效率结果；这些指标未测，不填零。

下一步在与本轮八个母事件不重叠的开发样本上估计空间照明分区及恢复状态，同时验证原始输入的孤立能标与共享弱分量响应，冻结后再做独立母事件确认。空间分布只能由开发样本预先确定，不能把待重建事件的真实光子落点作为算法输入。暂不在本批四对母事件上调恢复强度或有效微胞数，也不直接扩大未知K/t或高计数率拟合。

## 固定设计

- 继续使用2026-11-01的八个光学母事件及其实际沉积能量，保留母ROOT、种子和原始哈希。强→弱间隔8、40、200、1200 ns，弱→强40 ns。
- **原始位置**保持不变；**打乱顺序**在同一母事件的有效面内光子间联合置换XY，完整保留空间边际计数，改变时间/光子能量与位置的关联；**均匀位置**将同批有效面内光子的位置独立均匀化。
- 每个光子的到达时间、能量和有效面归属逐项保留；有效面外光子所有字段不变。每个母事件四个位置种子，每种八个数字化种子，跨条件和三臂配对。原始臂四个位置块仅用于对应数字化种子，本身没有位置变动。
- 每个条件/位置/数字化重复进行共同微胞及两次孤立数字化，分别开启/关闭恢复，共11,520次正式数字化；另24次旧案例重放与36次成本先导。重复数字化不增加独立光学母事件数。
- 位置随机数为`SeedSequence([713010001,parent,layout,arm_index])`；数字化种子为`713100000+block*10000+layout*100+repeat`，全部任务明细在`plan.json`。变更雪崩会改变后继随机数的消耗，不假设所有雪崩逐项相同。

主端点为同一2048 ns观测窗的弱分量电压面积变化：`100×(共享面积/本臂孤立面积−1)`。每个母对先计算重复均值之比，再对四个母对等权平均。4096 ns内的完整祖先电荷另存；2048 ns波形包含各分量及完整含噪模拟电压。面积单位相消后的百分比不能直接当作能量偏差。

模型和器件参数沿用上轮冻结配置，不用本批结果拟合恢复强度。除了既有孤立锚定模型，还预先保存直接使用同批光子时间、能量和有效面光子数的均匀年龄模型预测；后者是额外真值辅助的前向诊断，保留暗计数历史和邻胞串扰闭合近似的限制，不作为盲拟合输入。

不确定度采用10,000次配对嵌套重采样，依次重采样母对、位置块及数字化重复，重新计算同一个均值比端点。只描述这四对历史母事件，未包含独立输运、器件或光耦合系统误差，也未对多个条件提供联合覆盖保证。

协议在数字化前冻结：短间隔均匀化效应至少3个百分点且配对区间下端大于零、恢复关闭端点绝对值不超过3个百分点，用于支持所选母事件中的空间贡献。变换输入后通过模型检查，不等于原始输入通过；本实验不直接推进能量拟合或替换默认算法。

## 保存与重放

`source/`保存实际数字化、模型和相对导入依赖；`report/`保存统计和绘图模块。`source-config-freeze.json`、`input-freeze.json`和`report-freeze.json`分别固定源配置、光子输入及报告实现。数字化结果、光子数组、模型数组、图像和Notebook只在本地维护。

在项目根目录保留本地输入/模型数组后，可编译并重放到新目录：

```bash
mkdir -p pileup/experiments/alpha_pair_illumination_20261102/bin
g++ -O3 -std=c++17 -fPIC -shared pileup/experiments/alpha_pair_illumination_20261102/source/pileup/analysis/sipm_age_mean.cpp pileup/experiments/alpha_pair_illumination_20261102/source/pileup/analysis/sipm_age_mean_jacobian.cpp -o pileup/experiments/alpha_pair_illumination_20261102/bin/age.so
python3 -B pileup/experiments/alpha_pair_illumination_20261102/run.py replay --ids 4 19 --output jupyter/artifacts/illumination_replay_new
python3 -B pileup/experiments/alpha_pair_illumination_20261102/run_report.py validate
python3 -B pileup/experiments/alpha_pair_illumination_20261102/run_report.py report
python3 -B pileup/experiments/alpha_pair_illumination_20261102/run_plots.py
```

实际运行使用最多4个进程、BLAS单线程。源码哈希、环境、实际种子、输出、先导成本及重放核验完整保留。报告汇总全部预定条件，不依据结果挑选母事件、位置种子或数字化重复。
