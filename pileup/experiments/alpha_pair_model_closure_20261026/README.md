# 原生模拟与匹配高斯模型的逐事件恢复对照

本实验固定原面积守恒联合似然、候选搜索及物理参数，比较原生光子／共同微胞波形和由拟合模型自身均值、协方差生成的高斯波形。目的是检查恢复困难能否在该统计模型内重现，以及响应／噪声近似是否值得继续修正。本轮不训练网络、不选择新默认算法、不生成新ROOT。

## 已完成结果

使用同一原生门槛，严格整对成功如下；各点原生40对、高斯80对，高斯为每个相同参数点两次噪声抽样。

| 组合与输入 | 8 ns | 40 ns | 200 ns |
| --- | ---: | ---: | ---: |
| mid_mid，原生 | 40/40 | 40/40 | 40/40 |
| mid_mid，匹配高斯 | 80/80 | 80/80 | 80/80 |
| high_weak，原生 | 0/40 | 0/40 | 20/40 |
| high_weak，匹配高斯 | 0/80 | 0/80 | 42/80 |
| weak_high，原生 | 27/40 | 34/40 | 40/40 |
| weak_high，匹配高斯 | 56/80 | 75/80 | 80/80 |

改用高斯门槛后，上表严格双事件成功数全部不变。该门槛用于原生high单事件，额外输出从0/80升到7/80；高斯high控制为2/160。共用原生门槛时，原生／高斯控制仅mid有1/80和2/160额外输出，其余空／单组均无额外输出；四档单事件Q偏差中位绝对值均小于0.10%。

high_weak辅助诊断中，已有K=2、真实初始化、固定真实时刻三种结果如下。它们都不是盲恢复率或严格上界。

| 输入与辅助信息 | 8 ns | 40 ns | 200 ns |
| --- | ---: | ---: | ---: |
| 原生，已有K=2 | 0/40 | 3/40 | 20/40 |
| 原生，真实Q/t初始化 | 12/40 | 9/40 | 29/40 |
| 原生，固定真实t | 8/40 | 12/40 | 31/40 |
| 高斯，已有K=2 | 0/80 | 2/80 | 42/80 |
| 高斯，真实Q/t初始化 | 12/80 | 24/80 | 56/80 |
| 高斯，固定真实t | 15/80 | 29/80 | 56/80 |

高斯high_weak、40 ns的80对中，21对在真实初始化后由错误变为严格正确，但同一代价没有更低。单纯降低NLL并不能保证逐事件参数更准确。200 ns高斯与原生的盲恢复差为+2.5个百分点，配对母事件块95区间[−17.5,+18.75]，不据此声称两种生成模型等价。全成／全败点的bootstrap差值区间退化为零，只是样本重抽的性质。

真实参数白化后，high_weak、40 ns平方范数／1021的中位为原生0.9967、高斯0.9919，但残差偏度中位分别约0.251和−0.0049；原生保留正偏、正尾与少量相邻相关。模型仍是近似，只是短间隔失败在模型完全匹配时也存在。16个预定边界扰动未改变输出K或严格成功。

5项采样数值测试通过，4560条盲评分、56条汇总、2880条辅助评分、48条辅助汇总及2280帧真参数残差已核验。盲候选代价重放差为0，辅助候选最大相对差1.99×10⁻¹⁴；原生对应组与此前结果逐项一致。原生／高斯采用原生门槛时最终候选未收敛15/760、32/1520，全部计入结果。5幅图已视觉检查，历史Notebook单元保持。

采用结论：不更换默认算法或门槛；下一步拆开第二事件检出与Q/t估计精度，量化弱分量的联合不确定性，再有针对性地比较估计或搜索改进。本轮没有证实普适分辨极限。

## 输入及条件

- 原生760帧取自已公开的 `alpha_pair_joint_confirmation_20261026` 最新批，经 `alpha_pair_weak_search_20261026` 缓存：mid_mid、high_weak、weak_high × 8/40/200 ns × 40对，另80空窗和weak/low/mid/high各80个单事件。它们是开发／诊断资料，不再称为独立测试。
- 匹配高斯1520个评价帧：每个原生参数点两次独立噪声抽样。另280个门槛母样本参数点各抽一次，只标定门槛；共1800次新盲拟合。原生评价320个母事件与训练280、门槛280个母事件互不交叉。
- 固定95/351 ns闪烁双τ、2 ns × 1024点、完整0–2048 ns模拟电压、足够动态范围和未知局部K≤2。没有ADC削顶拒绝，也没有修改物理源率或生成新的随机高率窗口。
- 原生Q为已实现雪崩等效pe，高斯Q为数值相同的条件参数，不是重新模拟的一批雪崩电荷，也不是源／沉积／可见能量。t沿用有效SiPM面首光子时刻。

原输入、准备数据、母事件分组、Git版本及已有改动在本地 `jupyter/run_records/alpha_pair_model_closure_20261026/` 留档。当前源条件从既有运行记录沿用，没有用当前宏推断历史条件。无需新增Run_Catalog条目。

## 生成及拟合

固定FIR变换舍弃前三个瞬态输出，模型定义的是1021维边缘分布。其协方差C=B−VVᵀ由带状Cholesky与秩≤2修正精确开方，采样后逆FIR回到电压。前三个电压残差设零，没有凭空补一个窗前平稳分布。读出2/20/2 ns和闪烁95/351 ns是不同参数。

预先选择8帧，各加两种±[0.3,−0.3,0.3] mV残差前缀对应的FIR零空间分量，共16个边界对照。它们在变换后的似然里等价，但可检验有限候选搜索对电压前缀的敏感性。它们不替代真实硬件的窗前历史模型。

随机数为PCG64，SeedSequence熵由 `[20261026,7101]` 加角色、抽样编号、原池索引构成；1800个流各异。没有缩放波形、截除噪声尾部或按结果挑选种子。四个预定参数点各4096次抽样，另做稠密矩阵、白化、FIR往返等数值核验后，先完成32帧盲拟合与2帧辅助诊断小样本，再运行全量。

盲推断使用原 `waveform_candidates`、候选依赖C及logdet、全部原始搜索界限和预算。worker仅接收电压及序号，读取ROOT、truth和case标签会被拒绝。真值只用于生成、评分和下面明确标注的诊断。

四个组合为原生／高斯输入分别配原生／高斯门槛。主比较共用原280个原生单事件门槛；次比较以280个高斯单事件重新标定后交叉应用。增峰统计max(NLL₁−NLL₂,0)，拟合单Q按1500/5000/12500 pe分档，加一且包含并列的上尾秩p≤0.025；原拟合Q≥500保护保持。评价数据没有用于调门槛。

## 评价与诊断

严格整对成功仍要求两真实Q≥500 pe、各Q相对误差≤20%、各t误差≤min(10 ns,间隔/4)、无额外输出。另保存漏检、误拆／误并、普通10 ns匹配及匹配后的Q/t误差。未匹配输出也计为额外，不能都称为无信号处的假脉冲。

两类强弱方向各三个间隔，原生240对复用此前诊断，高斯480对做相同诊断：已有K=2候选、真实Q/t初始化（t半径48 ns，最多200迭代）、固定真实时刻拟合Q（七个观测总Q分配初值，各最多100迭代）。它们使用额外真值或不同预算，不是盲性能或理论上界。

在真实参数处另白化760原生和1520高斯帧，保存平方范数／1021、偏度、超额峰度、滞后相关及完整白化数组。χ²₁₀₂₁参照仅对模型正确且参数为真值的高斯数据成立，不称作拟合后的约化χ²。

恢复差异用40个母事件块、前20／后20分层、2000次配对bootstrap，跨方法／条件／间隔共享块权重；每个参数点的两次高斯抽样保留在同一块内。区间条件于这批参数、已拟合模型和抽样设计，不含训练或真实探测器全部不确定性。

## 文献边界

采用Fixsen等2004条件均值／非平稳协方差的思路，DOI [10.1016/j.nima.2003.11.313](https://doi.org/10.1016/j.nima.2003.11.313)。共享库已有笔记记载TES模拟、每能量5000次，PDF2式1–2及PDF3，AI草稿待人工审核。本轮只读复用，没有新精读或修改共享库。原文是协方差加权最小二乘；本项目的logdet、精确高斯采样及闭合对照不归于原文。采用记录见 [L58](../../../docs/literature-use.md#alpha-pair-model-closure-20261026)。

本轮不提供全局优化证明、普适最小间隔、free-τ最短窗、最高注入率、α/γ混合或随机高率K≥3性能。即使匹配模型仍失败，也不能证明所有算法都不可能分离；高斯模型表现好也不能直接外推实物探测器。
