Bretz、Hebbeker、Kemp（2020），*Extending the dynamic range of SiPMs by understanding their non-linear behavior*，预印本 DOI [10.48550/arXiv.2010.14886](https://doi.org/10.48550/arXiv.2010.14886)，[论文网页](https://arxiv.org/abs/2010.14886)。核对原文PDF第19–24页（印刷页18–23），§5.1、式5.8/5.12/5.14。作者主页仍列在unpublished papers中，本轮未核验到正式期刊版。共享库未检出独立原文/精读，既有引用提及不视为收录；只读访问，未下载入库或修改审核状态。

论文用S13360-6025PE、57600微胞，着重较高信号下的总光子数恢复，不是当前GAGG/6050PE、14400微胞下的逐事件弱α能量结果。项目仅采用“Bayesian反卷积→恢复模型乘法反演”的结构；没有复现作者完整电路Monte Carlo，也不能把本轮失败归结为原论文方法无效。

280 fold0单脉冲用于独立标定各变换域的能量条件形状，80空窗给出背景；32个不同评价母对应64帧。主方案RL128＋恢复；RL128/RL512/恢复512为对照。输入为完整1024×2ns电压，K/t明确给定，E/Q不进入推断。恢复模型采用2ns细胞年龄分布、29ns恢复、14400微胞、相对PDE和平均场瞬时串扰；这是项目近似。RL目标/末端对角权重不是物理精确似然。所有实际配置和公式选择见protocol.json，原始随机种子和母ROOT身份见本地calibration/labels.json、labels.json及input-freeze.json。

评价只用32个不同光学母事件，多种间隔/方向复用同一母事件，64帧不能当作64个独立输运样本；这些历史母事件曾被研究，只是本次新参数的回顾性留出。每条件8条，不作显著性或总体性能排名。既有GLS还使用过900对开发波形做均值标定，本轮新流程只用孤立事件；这是可用流程的比较，不是训练信息完全相同的算法优劣证明。真实K/t已给定，漏检、额外输出、误拆分、误合并、时间误差和α/γ分类效率均未测，不能填零。

8ns的8/8弱E下界解不代表高分辨率。按预先方案停止在64帧，未达到扩480门；主方案相对GLS新增2/失去7对。低Q、边界及失败均未过滤。源码、模型、输入、输出哈希及评分表保留；npz/PNG与Notebook按项目约定只在本地。

实际完成5项数值测试，覆盖有限窗伴随、SPE电荷单位、RL目标下降、恢复因果/低率极限、非线性逆解及2/1 ns网格收敛；四个实际标定模型共24个无噪声E逆解，最大相对误差1.1e-09，各80能点的积分响应单调。280标定母与32评价母不重叠；推断读取标签的尝试被实际拦截。256条新拟合和64条旧GLS参考、480条分量评分全部保留，128次评价恢复反演和256次能量优化均报告收敛（不证明物理模型正确或全局最优）。冻结源码重放id40/120的8条拟合，与原结果完全一致。6进程、BLAS单线程，标定360帧约185.0秒，评价约83.1秒。

## 复现

在项目根目录、保留本地输入/模型数组和Python环境时运行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 bash tools/run_gagg_python.sh pileup/experiments/alpha_pair_deconvolution_20261030/replay.py --output jupyter/artifacts/alpha_pair_deconvolution_20261030_replay --workers 6
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 bash tools/run_gagg_python.sh pileup/experiments/alpha_pair_deconvolution_20261030/run_report.py
```

replay调用冻结source目录，不依赖切换Git。输出目录必须新建，不覆盖已有结果；--ids 40 120可做两帧重放。prepare/calibrate/run是初次构建流程，会拒绝覆盖冻结实验。source-freeze记录当时算法；report-source-v1保留图58布局调整前报告源码/哈希，当前report-source-freeze为修订图例布局的版本，数值结果一致。sandbox-retry记录初次进程池本地套接字受限后的相同命令授权重跑。
