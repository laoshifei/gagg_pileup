# Calibrated residual births and physical weak-alpha controls

本轮处理上一轮低电荷单脉冲被误拆的问题，同时加入实际电荷约500–1000 pe的弱α事件。已有均值响应、双衰减时间95/351 ns及SiPM物理配置保持；无新网络训练。拟合只读完整含噪电压，推断未知局部K≤2。

先导源能量1.5、1.75、2.0 MeV各4个ROOT，实际电荷中位数约423、1034、1583 pe；追加1.625 MeV的4个ROOT，中位约713 pe。随后用80个新1.625 MeV母ROOT构造1400个共同微胞双事件和80个原生单事件。源能量不是沉积能量或可见能量；Q是雪崩等效pe，没有缩放光子或相加独立电压。

初始方案仅在原残差搜索后加入单事件经验分布筛选，低Q单事件误拆由12/160降至3/160，但弱单事件Q偏差中位仍为−10.10%，因此未通过全部要求。初始结果保存在`null-selection.json`。

进一步用观测电压的单事件OLS拟合构造平滑模型，再从该模型形成每帧固定的经验GLS权重（ρ=0.9）。所有K/Q/t候选共享该矩阵。开发小样本中，模型先验权重将弱单事件偏差由约−10%改为约−1%；这是项目实算诊断，不是修改器件的物理相关系数。

新增事件的证据为完整候选搜索后的代价改善，比较除以单事件残差或零模型代价两种评分。以拟合的单事件Q分四档，用560个开发单事件的经验上尾秩标定，采用加一修正、保守处理并列、固定门槛0.025。最终模型权重方案以该秩替代K1→K2的固定惩罚，零／单事件检测保持原判据。该秩不是第二个事件为假的后验概率，也不保证模型失配时的误报率。

模型权重开发数据共3120帧：此前两批已公开数据各取每点前10对及全部控制，加上新的1480帧弱脉冲开发数据。响应模板未重标定，全部旧数据明确作为开发使用。选择要求各空／单控制额外输出点估计≤5%、各单事件成功≥95%、各单事件Q偏差中位绝对值≤5%，再最大化强／弱两类组合等权恢复率。`model-null-selection.json`选择`relative_residual`；弱单事件Q偏差约−1.06%，弱双事件平均整对成功约49.7%。这些控制样本同时参与秩标定，独立性能必须由后续新样本评价。

## 独立测试协议

冻结后另生成1.625、2.5、5.486、8 MeV各80个母ROOT，共320个；十种电荷组合、4/8/12/20/40/80/200 ns、每点40对，另有80空窗和320原生单事件，共3200帧。跨间隔／条件复用母样本，不把帧数当独立曝光数。两事件均Q≥500 pe才进入整对恢复分母，全部生成帧和阈下数量另报。成功要求各Q误差≤20%、各t误差≤min(10 ns,Δ/4)，且无额外输出。

对照包括原观测权重＋固定惩罚、模型权重＋固定惩罚、两种模型权重＋经验筛选，以及明确使用真实K的诊断；后者不是盲方法。完整时间窗的两个示例预先固定为high_weak第0对、40和200 ns。没有根据独立测试选择阈值或展示样本。

从项目根目录运行（本机环境入口为`bash tools/run_gagg_python.sh`）：

```bash
bash tools/run_gagg_python.sh pileup/experiments/alpha_pair_null_gate_20261023/production.py
```

`freeze.json`保存实际分析代码、物理源码、配置及选择的哈希；需要本地ROOT、响应数组和依赖，GitHub不分发这些数据或本地Jupyter笔记。ROOT、实际宏、种子和恢复记录保存在各阶段`manifest.json`及本地Run_Catalog。

开发阶段经历主机重启：13个已登记完整ROOT经哈希复核，另1个完整ROOT经RunInfo／宏／种子核验后恢复登记；4次未完成尝试保留原文件或缺失状态，使用相同预定种子重跑。未根据物理结果挑选重跑样本。
