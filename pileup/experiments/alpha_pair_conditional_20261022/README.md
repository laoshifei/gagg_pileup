# 电荷／邻近事件相关响应与选择性重拟合

本实验继续检查此前固定模板把网络的短间隔电荷分配拉偏的问题。研究范围是纯 α、固定 95/351 ns 双发光寿命、2 ns 采样、2.048 μs 局部模拟电压、已标定基线和未知 K=0/1/2。动态范围充分，不按 ADC 触顶删窗。Q 是实际雪崩等效 pe，不是源能量或沉积能量。

## 方法与数据边界

- 用上一轮 `alpha_pair_resolution_20261022` 的母 ROOT 开发；此前的测试数据在这里明确降为开发数据。按母样本编号的双事件块分组，训练和选择规则各 120 个母 ROOT，没有跨组复用。
- 训练使用真实祖先分量、Q 和首个有效面光子时刻，拟合 9 项正则化经验响应修正。特征包括本事件 Q、估计的邻居 Q、相对时刻及固定时间尺度的包络。它是可从盲估计计算的状态代理，不输入模拟器的真实微胞状态；不是逐事件 free-τ。
- 为经验修正加因果起始约束，未观测尾部不作为零值参与标定。采用原始模拟参数生成数据，未改变晶体或 SiPM 物理参数。
- 形状涨落用异方差 AR(1) 残差近似。每帧的协方差由观测电压的固定平滑先验确定，同一帧所有 K/Q/t 候选使用相同矩阵。因此比较时 logdet 是常数；这是经验 GLS，不宣称精确微观似然或全局最优。
- 分别保存仅波形候选的条件拟合、增加两个冻结网络起点的条件拟合、仅修正均值的混合方法、相关加权混合方法，以及按观测间隔和电荷改变量决定是否接受重拟合的流程。两套网络是既有同架构的两个种子，本轮没有重训新网络。
- 新均值／新 GLS 均在盲起点附近 ±16 ns 联合优化时刻与 log Q，设置 `max_nfev=60`（数值 Jacobian 调用另计），Q 边界为 50–50000 pe；原固定模板流程是 ±12 ns 变投影。新均值与新 GLS 使用相同优化器，可比较加权作用；旧／新比较是整个流程的比较，不能把所有变化归于一个因素。
- K 惩罚和接受规则只在开发验证母样本选择，要求空窗及低／中／高单事件组各自额外输出比例 ≤5%。独立测试前冻结源代码、模板、模型权重与选择规则。

## 独立验证协议

源能量 2.5、5.486、8 MeV 各 80 个新光学母 ROOT，中央入射。ROOT 保持原生单事件；双事件由这些新光子离线共同推进微胞生成，没有缩放光子或独立电压相加。G4 每进程串行、每 ROOT 一个 WaveformEvent，最多 4 个进程并行，启动至少相隔 1 秒。

原生记录为20 μs；离线共同数字化使用4.096 μs，分析前2.048 μs电压，Q按各自实际记录窗内的祖先雪崩计量。`prefill_photons.py` 可提前用2个工作进程提取已验证ROOT的前200份光子缓存，与4个原生任务重叠时最多6个计算任务；校验ROOT哈希和缓存数组，不改变物理、种子或重建规则。辅助脚本首次默认forkserver启动受环境限制，改为显式spawn；主生产未受影响。

低低／中中／高高／先弱后强／先强后弱五组，Δ 为 4、8、12、20、30、40、60、80、120、200 ns，每组每点 40 对。另有 80 空窗和 240 原生单事件。相同母样本跨间隔和部分条件复用，2320 帧不能当作 2320 次独立物理曝光。这个网格不能替代上一轮 0–800 ns 的完整扫描。

主指标：两个真事件 Q≥500 pe；每个 Q 误差≤20%；每个时间误差≤min(10 ns, Δ/4)；一对一恢复且没有额外输出。同时报告条件 Q 偏差／分辨率、漏配、额外输出、误拆／误并标志和空／单控制。误拆／误并为匹配邻近图定义的操作指标，不是唯一物理因果判定。逐点 Wilson95 区间及同点配对 bootstrap 差值不构成所有条件的同时保证。

## 独立结果

240个母ROOT和2320帧均已完成，13流程共30160条逐帧评分。下表为同一批新测试的整对成功数，每点40对；“新GLS”使用电荷／邻居相关均值与经验相关权重，保持各自网络预测的K。两种子分别列出，没有在测试点选择较好种子。

| 条件／间隔 | 原网络1／2 | 原固定模板混合1／2 | 新GLS混合1／2 |
| --- | ---: | ---: | ---: |
| 中／中，8 ns | 19／31 | 0／0 | 40／40 |
| 中／中，20 ns | 32／9 | 4／4 | 40／40 |
| 高／高，8 ns | 3／5 | 0／0 | 40／40 |
| 先弱后强，8 ns | 0／2 | 0／0 | 36／36 |
| 低／低，30 ns | 34／38 | 40／40 | 34／34 |
| 先强后弱，200 ns | 0／3 | 0／4 | 0／4 |

中／中及高／高在8–200 ns各已测点的新GLS均40/40；40/40的逐点Wilson95区间约91.2%–100%，不能保证全部条件或更短窗口。中／中8 ns仅修正均值、无相关加权的种子1为1/40；仅旧波形候选起点的新GLS为0/40，加入网络起点为40/40。新均值、权重和起点的作用须分别检验。

低电荷原生单事件新GLS的Q相对误差中位约−14.24%，成功76/80；仅均值修正为−0.68%、80/80。先强后弱200 ns，网络1／2分别40／36帧只报一个事件，保持K的重拟合无法补出第二事件；重新比较K的条件拟合为36/40，原盲拟合为39/40。原盲拟合同时有34/80高电荷单事件额外输出；新GLS及条件K选择的空／低中高单事件各组均0/80，Wilson95上限约4.58%。不能据双事件曲线单独判优。

开发阶段选中的接受规则近似接受所有收敛的新GLS重拟合，收益不能归于门控本身。后续优先修正低Q相关权重偏差、引入残差新增候选及K比较，再验证新位置／源能量和α/γ；本次不根据测试条件拼接方法或重选阈值。

实际宏、RunInfo和种子已核对；新源种子与25份旧运行清单分离，推断标签访问拦截通过。分量闭合最大误差3.18×10⁻¹² mV，预定新4 ns样本的标量／优化数字化重放完全一致，三项针对性测试通过。`science-validation.json`、`test-report.json`和`test-diagnostics.json`保存完整验证与结果，跨间隔复用母样本不作为独立曝光。

## 运行与保存

从项目根目录使用项目 Python 环境。运行前需要本地输入 ROOT、既有模型权重及分析数组；这些二进制和 Notebook 不随 Git 分发。冻结后使用本目录入口，避免未来 live 模块变更影响重放：

网络推断另需与本次记录一致的PyTorch 2.14.1+cpu。本机旧的可选 `/tmp` 安装目录曾丢失；`restore_ml_runtime.py` 用旧安装清单和缓存wheel的SHA256离线恢复，`resume_inference.py` 先复算两个网络各64份旧观测，再从推断阶段续跑，不重做仿真。本次复算的Q、t及分类概率逐项完全一致。此恢复入口依赖已有本地缓存及安装清单；其他系统需配置相应CPU环境，并记录版本与复算检查。

本机恢复后可用 `PYTHONPATH=/tmp/gagg-correlated-ml-deps-20261020` 指向可选依赖；不要将其误当成所有系统都有的固定目录。

已完成的生产清单和数字化检查点可续跑；保留全部 ROOT、失败尝试和旧结果。新物理配置应创建新实验，不覆盖本目录。G4 源码在 `source/brems/g4`；需要时在新构建目录编译，并核对已有二进制标识和配置差异。

本地结果在 `jupyter/artifacts/alpha_pair_conditional_20261022/`，包括观测／真值分离文件、原始盲预测、开发及测试完整评分。普通文件临时缓存用于减少共享盘 I/O，不创建链接；最终数据回存共享盘，临时缓存丢失后可从持久结果恢复。运行审计在 `jupyter/run_records/alpha_pair_conditional_20261022/`。过程和带固定图号的输出已写入 codex_0004 第41–44节；原有计算、图像和图号保留。`deliver.py`的结果解释只读取冻结评分，实际执行新增展示单元，不重跑历史计算，也不改变冻结推断源码。

本方法只检查上述模拟域。未覆盖新的光学位置、500–1000 pe 物理弱信号、free-τ、α/γ 混合、随机高率 K≥3 或实物数据；时间间隔恢复率的倒数不是最高计数率。

仅波形起点的对照先继承原固定模板已经选出的一个K=1及一个K=2候选，再在新响应下局部优化，不能代表对新响应进行充分多起点／全局搜索后的纯拟合上限。加入网络起点的版本也保持盲推断，但其收益同时包含搜索起点的帮助。
