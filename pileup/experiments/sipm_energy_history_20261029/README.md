# 共享微胞响应与能量误差诊断（2026-10-29）

孤立单事件能标通过，并不保证堆积中的同一沉积能量仍产生相同分量电荷。本轮在当前GAGG/SiPM模型中定位响应变化和拟合变化，不训练模型、不重新拟合波形，也不调整静态能标或选门。

前一阶段代码基线为`73a4e94fbfa5bcc8d6516c00590721de2b468844`。本实验创建时的新增诊断源码直接保存在`source/`并冻结，不需要切换Git提交。笔记与原始数据保留本地。

## 实际完成的对照

历史部分复用1600帧中的1200对双脉冲，对2400个真实分量与4800个方法分量位置作误差分解。每个分量回溯同一光学母事件的原生孤立Q。冻结能标记作g，沉积能量记作E，则：

```text
(g(Qfit)−E)/E = (g(Qnative)−E)/E
               + (g(Qshared)−g(Qnative))/E
               + (g(Qfit)−g(Qshared))/E
```

三项在同一有限、普通10 ns时间匹配子集上取均值，不能把中位数相加；漏检和域外值单独保留。历史原生Q使用C++/20 μs、共享Q使用离线/4.096 μs，随机数也不同，因此第二项本身不是纯恢复效应。原2.048 μs盲拟合波形及结果不变。

新离线部分固定8组已有弱/强α光学母事件，每组4个数字化种子；两个顺序、8/40/200 ns三个间隔。弱/强源能量分别为1.625/8 MeV，实际沉积0.204–0.286/7.572–7.616 MeV。每个共享分量与同一光子母事件在同位置、同窗口、同配置下独立数字化的Q比较。首次光子参考起点为窗口t=128 ns，常规窗口4.096 μs。

配置对照仅将`recovery_enabled`由True改为False。关闭恢复组相当于微胞总是完全恢复，连带改变当前模型中恢复相关的PDE、雪崩电荷及串扰；不把各机制分开归因，也不将其作为新器件或默认配置。关闭恢复组只评价Q，不使用原能标评价E。

912次数字化包括384次共享双脉冲、512次孤立位置控制、16次20 μs长窗控制；实际用2进程、234.72秒完成，没有新ROOT。每组仅4个数字化随机种子，不是912个独立物理事件。每个母对/重复使用相同种子对照，但改变合并光子顺序会改变随机数的逐光子分配。

## 结果

下表为弱分量共享/孤立电荷比减1。先对各母对的4次数字化取平均Q后求比，再对8个母对等权平均。

| 顺序 | 间隔 / ns | 正常恢复 | 关闭恢复 | 正常恢复下已知共享Q的平均E偏差 |
| --- | ---: | ---: | ---: | ---: |
| 先强后弱 | 8 | −15.78% | +0.01% | −21.03% |
| 先强后弱 | 40 | −15.68% | −0.85% | −20.90% |
| 先强后弱 | 200 | −8.24% | −0.03% | −10.91% |
| 先弱后强 | 8 | −14.88% | −0.22% | −19.83% |
| 先弱后强 | 40 | −11.28% | +0.92% | −15.02% |
| 先弱后强 | 200 | −6.54% | −0.56% | −8.55% |

对8个母对及每对4个重复进行2000次配对嵌套bootstrap。先强后弱8 ns的正常恢复Q变化条件95%区间为[−17.27%,−14.06%]；恢复开−关配对差为−15.79个百分点，区间[−16.41,−15.18]。所有关闭恢复的Q变化区间都覆盖零。这支持当前模型的共享微胞恢复是系统损失的重要来源，不是实测6050PE性能结论；29 ns恢复时间仍为同系列代理值。

即使知道真实分量Q并用冻结孤立能标换算，先强后弱8 ns的弱E也平均低估21.03%，仅1/32次数字化结果在能量±10%内；对应孤立控制29/32。这里已知分量归属，不是盲恢复率。正常恢复各组反演32/32有限。强分量Q损失约0.2–0.5%，远小于弱分量。

历史先弱后强200 ns、联合NLL的弱分量平均能量误差只有+0.73%，但分解为孤立能标+1.97%、响应变化−9.54%、拟合变化+8.30%；29/40个有限匹配分量表现为描述性的偏差抵消。误差均值小不等于电荷分配准确。先强后弱8 ns仅1个NLL普通时间匹配，不能用这个子集的均值代表全部40个事件。

历史计数保留：模型GLS/联合NLL分别漏检152/161个真分量、额外输出22/27个，严格能量成功1578/1623个（真分量各2400），整对成功500/549个（各1200对）；误拆标志1/0、误并标志103/100。它们都是原拟合输出的再汇总，本轮没有提高任何盲恢复指标。严格端点仍要求E±10%、时间误差≤min(10 ns,Δt/4)、整对无额外输出。

16例长窗控制中，20 μs总Q在窗口t=2.048 μs之后最多占0.8436%，t=4.096 μs之后最多占0.00602%。同种子长窗截取的4.096 μs初级后代Q与短窗结果完全一致；不能用4.096 μs后的积分尾巴解释上述损失。首次光子参考t=128 ns，故两时刻分别距参考1.920/3.968 μs。此检查没有排除短电压窗对拟合的影响。

## 输入、源码及复现

从项目根目录，用`bash tools/run_gagg_python.sh`或已配置的项目Python执行；以下命令均相对于项目根目录。本地输入须先就位并匹配`input-hashes.json`，Git仓库不分发原始ROOT、光子NPZ和历史拟合数据。

```bash
bash tools/run_gagg_python.sh pileup/experiments/sipm_energy_history_20261029/run.py pilot
bash tools/run_gagg_python.sh pileup/experiments/sipm_energy_history_20261029/run.py historical
bash tools/run_gagg_python.sh pileup/experiments/sipm_energy_history_20261029/run.py simulate --workers 2
bash tools/run_gagg_python.sh pileup/experiments/sipm_energy_history_20261029/report.py
```

`historical`拒绝覆盖已有完整分解；`simulate`按任务核对完成记录并续跑，保留每次结果。报告读取固定结果，可再生CSV及PNG/SVG。已有结果不应通过删除原文件来重跑；如需改变物理配置或计划，创建另一个实验。

- `protocol.json`：诊断问题、样本、控制、统计口径与限制。
- `source/`、`run.py`、`freeze.json`：实际仿真与分解源码、原配置和运行器冻结。
- `sensor-config*.json`：恢复开/关配置，只有恢复开关不同；另一文件另有说明文字。
- `simulation-plan.json`：全部912个任务；雪崩种子691000000+slot×100+mc，slot=0…7、mc=0…3。
- `photon-inputs.json`、`input-hashes.json`：16个母ROOT身份、原光学种子、输入路径及缓存校验值。本轮不重算所有ROOT字节哈希。
- `energy-model.json`：上一轮已经冻结的PCHIP，未重新选择或拟合。
- `report.py`、`report-source-freeze.json`：最终实际报告源码。`report-revisions/unused_v1/`保留完整报告执行前被修正的一条暗事件前缀注释及旧版本；仿真代码/数据/统计口径未改。
- `result-summary.json`、`tables/`：可随代码审阅的结果与明细汇总。
- 本地结果：`jupyter/artifacts/sipm_energy_history_20261029/`；环境、备份和验证：`jupyter/run_records/sipm_energy_history_20261029/`。

校验包括：历史电荷精确重放、2400分量的真实能量身份、误差恒等式闭合（最大8.9×10⁻¹⁶）、全部912任务与电荷归属闭合（最大7.3×10⁻¹² pe）、配置仅恢复开关不同、输入/源代码哈希及原盲输出保持。光子通过校验后的普通`/tmp`副本读取，不使用临时链接。4幅固定编号图0007-15-1至0007-18-1与计算输出已写入本地codex_0007；旧计算与图片保留。

## 适用范围及后续

当前为纯α、中央入射、固定95/351 ns双发光衰减、单一器件模型、局部K≤2、足够采集动态范围。选择的8对母事件已经用于历史评价；新数字化种子不能替代新独立输运确认。bootstrap不含能标或物理模型误差。未验证γ、free-τ、K≥3或连续率/绝对能谱，不给出普适最小时间间隔或最高计数率。

文献依据与AI待审状态沿用项目[采用记录L74](../../../docs/literature-use.md#sipm-energy-history-20261029)。本轮未实现Rosado2019的平均解析式，使用的是项目已有微胞模拟器。下一步应在独立开发母事件上建立含邻居/恢复历史的联合能量响应，冻结后另用新母事件验证；真值只能参与训练和评价，不能输入盲推断。
