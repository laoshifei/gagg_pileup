# 独立能量条件均值与残差噪声标定（2026-10-30）

本轮分别估计沉积能量条件下的平均波形与残差协方差，再比较“旧/新均值 × 旧/新噪声”四组固定权重GLS。预先指定的主比较为两者同时更新相对两者均不更新。**仍为纯α、给定真实事件数K与真实到达时间t，只拟合E_dep**；不是未知K/t的盲重建或α/γ混合性能。

## 方法与隔离

均值在冻结q0(E_dep)坐标上回归波形残差，使用既有9个自身电荷/前后脉冲历史特征；不以每条真实雪崩Q为回归坐标。各条件/间隔/分量分层等权，ridge=0.03（常数项0.0003），时间平滑sigma=4 ns；有限支撑和非负限制明确保留。仅平滑均值残差插值到相对时间网格，未观测尾部不参与回归。新增电压面积同步更新模型预测Q，未强制归一到真实Q；q0(E)只保留为冻结坐标，校正后孤立电荷可以与其不同。旧模板边界约定保持，不作任意连续时间下精确因果支撑的声明。

噪声使用另一组母事件上的原生FIR残差，不插值随机残差。空窗估背景尺度；非负模型活动度乘三参数指数估短程方差，条件变量为q0(E)与另一分量活动度，邻点/跨分量相关限制为±0.45。短程项拟合残差二阶矩，可含残余均值失配，不能称纯微观噪声。另按条件、间隔、分量与四个q0档中心化总面积残差，估正的长程幅度模式；本次四档原始估计均为负，按事先规则截为0。负估计及原值完整记录，不证明真实长程相关为零。

两套权重均由该帧电压导出的一脉冲初值及旧固定K/t能量解构造；新噪声取新均值，两套协方差在四组能量优化中各自保持固定。每套协方差由两种均值共享，因此可分别评价均值变化与权重变化。所有方法使用相同能量起点、范围和预算：单事件2起点，双事件7起点，每起点最多120次least-squares评价。未额外启用参数相关NLL或事后选最优方法。

推断只读取电压、明确给定K/t和冻结模型；实际读隔离拦截事件E/Q标签、标定样本和其他实验结果。真实E/Q仅供标定及独立后评分。每条结果记录边界、求解收敛、共同协方差能量及耗时。与上一轮16次参考平均波形构造权重不同，本轮使用单条观测初值；样本也不同，不能直接把旧32例分母与本轮40例相比作为增益。
