# 由独立开发样本固定的空间恢复模型

本实验接续位置随机化对照，将非均匀照明显式纳入微胞恢复状态。模型用于原始光子落点的响应验证；本轮不进行双脉冲能量拟合。

## 数据与固定模型

光照先验来自128个历史开发母事件：原联合标定fold0，在源能量1.625、2.5、5.486、8 MeV四组各按ROOT路径排序取32个。逐母事件用满恢复PDE对有效面内光子加权并归一，再等权平均。原ROOT哈希及历史配置核验，输入光子和RunInfo另存本地快照。

16个评价母事件来自2026-10-26的四能量组，各取编号块5、15、25、35。它们与128个先验母事件及上一轮16个因果控制母事件互不重叠。评价数据在早期研究中已经暴露，因此本轮是对新空间参数留出的回顾性检查，不称为新未见输运确认。

先验采用正方形D4对称平均，预先固定6×6及12×12分区；主方案为12×12、1 ns时间网格，另用12×12、0.5 ns检查时间离散变化。每分区有独立的恢复年龄分布。对称等照明分区的状态方程可合并为6或21组以减少重复计算，不代表不相邻微胞之间存在真实连接。

固定95/351 ns双衰减、快分量0.3、29 ns恢复代理、14400微胞和恢复修正强度1。分区内仍用原有prompt-crosstalk平均场近似，没有显式跨分区邻胞传播，也未在期望模型中加入暗计数恢复前史。模型不是实物器件标定。

电荷→入射光等效量映射使用与双脉冲**同一个空间算子**，81个250–40000满PDE等效光量结点积分至6144 ns，目标为已有孤立Q(E_dep)。因此共享修正与自身孤立响应保持一致，不沿用均匀模型的光量逆映射。

主预测是“原标定孤立电压＋空间模型的共享减孤立修正”。孤立电压按构造保持原样，不能用这一性质证明空间物理正确；本轮另检查真实光子时谱/PDE权重驱动的原始空间响应。原始响应仍用固定开发空间先验，不用评价事件的真实落点分布拟合参数。此检查使用额外真值，只作前向诊断。

## 顺序与判据

1. 固定母事件划分、先验、源码和协议，检查均匀极限、对称分组合并、导数、孤立不变性和因果支撑。
2. 完成64个孤立母事件/相位控制，每条8次数字化，共512次。已知到达时间，由完整含噪均值电压拟合单事件E；真实E不输入拟合器。
3. 孤立检查要求四组平均能量偏差在±5%内，相位跨度≤1个百分点，原始空间响应组平均面积误差在±5%内。通过后才进行20个双脉冲条件，每条8次重复，共同微胞/两孤立及恢复开关共960次数字化。
4. 双脉冲比较强→弱8/40/200/1200 ns、弱→强40 ns；端点为同一2048 ns窗内弱分量共享/孤立电压面积比。共享预测误差≤5个百分点，恢复关闭端点绝对值≤3个百分点，空间/时间网格差≤1个百分点。

单/双事件数字化完整窗口均4096 ns，观测比较明确取前2048 ns；保留完整祖先电荷。单事件的原始能量、入射源能量、光子能量和电压面积是不同物理量，分别记录单位，不把面积百分比当作能量偏差。

所有条件保留，不根据评价结果选择强度、微胞数或空间分区。区间按母事件/数字化重复做配对重采样；四母对不是大样本，也未包含先验估计或器件系统不确定度。最多4进程，BLAS单线程，无新ROOT。

## 已完成结果

128个开发母事件固定空间照明先验，16个不重叠历史评价母事件的孤立与共享响应均通过预设门。强→弱8/40 ns弱分量面积预测误差，由均匀模型的+7.11/+7.38个百分点降至−0.06/+0.54个百分点，五条件最大绝对误差1.09个百分点。原孤立电压锚定保持原样，另列真光子时谱前向诊断的强档原始面积误差由+7.99%降至+0.24%。这是回顾性响应验证，尚未进行双脉冲能量拟合，不能据此声称能量恢复或盲效率已经改善。

正式512+960次数字化，先导14次，重放104次，共1590次；正式孤立/共享阶段耗时11.3/30.9秒，最多4进程。一个非零相位孤立任务和两个双脉冲任务在新目录重放，物理数组逐项一致；先导与生产重合种子同样精确一致。新图为0007-82-1至85-1，本地Notebook0007第81–86节保留原140单元及输出。

评价母事件与128先验母、全部560旧均值/噪声开发母以及上一轮16因果控制母互不重叠，但早期研究已暴露这些评价数据。因此只称对新空间参数留出的回顾性检查，不称新未见输运确认。共享阶段仅四母对；数字化重复不增加独立输运样本数。10,000次母对/重复配对重采样条件于冻结先验，未传播先验估计与器件系统不确定度。本模型仍限当前中心入射纯α、固定95/351 ns双衰减及快分量0.3、29 ns恢复代理和14400微胞；分区内prompt-crosstalk平均场没有显式跨分区邻胞传播，期望响应未加入暗计数恢复前史。漏检、误拆分、误合并、重建效率、能谱选择效率与高率性能均未测，不填零。

下一轮单独冻结已知K/t的能量拟合实验：在同一物理含噪波形、同一权重及同一搜索预算下比较均匀与空间响应，并列报告逐分量偏差、RMSE、两能量均在±10%的严格成功数、边界和未收敛，所有失败保留在分母。先做模型内反演及孤立控制，再检查双事件；开发条件通过后增加不重叠母事件确认，再考虑未知K/t、α/γ和连续高率。本轮空间分区、恢复强度和微胞数未按评价输出调参，默认盲算法保持原样。

当前源码起点3a4d028在本轮工作前按用户要求推送；新实验实际执行代码以本目录冻结源码、兼容包装器及哈希为准。工作副本模块补入等价兼容处理，原冻结源码未改。文献层级沿用项目L87/L88；共享库不可用，本轮没有新增外部论文主张。

## 源码、兼容修订与重放

原`source/`与`run.py`保持冻结。初版运行器先遇到NumPy布尔值的JSON记录问题，随后父进程遗漏了已约定的NumPy1.26 `trapezoid`名称适配；单独的`run_v2.py`、`run_v3.py`记录两次兼容修订。当前入口为`run_v3.py`，只增加元数据类型转换、现有NumPy名称适配和确定性电荷映射检查点，不改物理公式、模型参数或输入样本。失败原因与原入口均保留。

在项目根目录、保留本地光子/模型数组和已编译库后，重放必须写入新目录：

```bash
python3 -B pileup/experiments/alpha_pair_spatial_recovery_20261102/run_v3.py replay --kind single --ids 3 --output jupyter/artifacts/spatial_single_replay_new
python3 -B pileup/experiments/alpha_pair_spatial_recovery_20261102/run_v3.py replay --kind pair --ids 1 4 --output jupyter/artifacts/spatial_pair_replay_new
python3 -B pileup/experiments/alpha_pair_spatial_recovery_20261102/run_report.py validate
python3 -B pileup/experiments/alpha_pair_spatial_recovery_20261102/run_report.py single
python3 -B pileup/experiments/alpha_pair_spatial_recovery_20261102/run_report.py pair
python3 -B pileup/experiments/alpha_pair_spatial_recovery_20261102/run_report.py plots
```

Git不包含模型数组、光子、波形、Notebook、图像或编译库。首次重放可按`build.json`中的项目相对命令编译`source/pileup/analysis/sipm_age_mean.cpp`和`sipm_age_mean_jacobian.cpp`生成`bin/age.so`，然后通过数值检查及重放核验。
