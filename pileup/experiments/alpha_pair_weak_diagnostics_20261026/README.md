# Weak-alpha recovery: truth-assisted failure diagnosis

本轮诊断强α后弱事件的失败机制，使用已经公开的上一轮测试资料，全部结果归为开发诊断。没有新增ROOT、神经网络训练或物理参数修改。`freeze.json`保存执行前的实际Python、物理源码和配置；运行记录位于本地`jupyter/run_records/alpha_pair_weak_diagnostics_20261026/`。

从320个光学母ROOT构造的旧资料中，预先取十种电荷组合×8/40/200 ns×40对，以及全部80空窗、320原生单事件，共1600帧。跨条件和间隔复用母样本，不把帧数累计为独立曝光。

纯α、固定95/351 ns双τ、2 ns采样、完整2.048 μs模拟电压、充分动态范围。Q为实际雪崩等效pe，不是沉积能量；t为SiPM有效面首光子时刻。整对成功要求两个真实Q≥500 pe，各Q误差≤20%、各t误差≤min(10 ns,Δ/4)，且无额外输出。

## 实现与诊断结果

| 方法 | 使用的真值 | high_weak 8 ns | 40 ns | 200 ns |
| --- | --- | ---: | ---: | ---: |
| 原观测权重盲流程 | 无 | 0/40 | 0/40 | 21/40 |
| 原模型权重＋经验筛选盲流程 | 无 | 0/40 | 0/40 | 19/40 |
| 原搜索，指定K | K | 0/40 | 4/40 | 19/40 |
| 固定真实时刻，GLS拟合Q | K、t | 3/40 | 13/40 | 28/40 |
| 固定真实时刻，OLS拟合Q | K、t | 5/40 | 13/40 | 32/40 |
| 真值启动，联合GLS | K、Q/t初值 | 1/40 | 8/40 | 26/40 |
| 真值启动，联合OLS | K、Q/t初值 | 1/40 | 8/40 | 24/40 |
| 精确减去另一真实分量 | K、另一分量及其Q/t、弱事件初值 | 40/40 | 40/40 | 40/40 |

固定真实时刻时，五个Q初值仅来自观测拟合总量的3%/15%/50%/85%/97%分配；Q依赖的条件响应仍是非线性模型。真值启动局部优化的时间半径24 ns、Q范围50–50000 pe、最多120次函数评估。oracle保留真实邻居条件和观测中的暗噪声／电子噪声，返回的另一事件直接使用真值，不能解释成盲性能或理论分辨上限。

同一GLS矩阵重放原候选代价的最大相对误差为9.73×10⁻¹⁶。40 ns组真值启动后的32个失败解全部比真值处代价低。优化随机数据后残差下降本身正常；结合参数错误及精确分量扣除对照，当前目标函数的低值不足以保证逐事件Q/t正确，不能只归因于起点搜索。oracle、OLS和完整GLS的代价作用于不同残差／权重，不能混比。

收敛核验：40和200 ns的真值启动GLS均40/40达到局部停止条件，最大函数评估次数分别25与17，低于120上限；不能把这些失败直接归为迭代预算耗尽。8 ns为39/40正常停止、1例达到120次上限，原结果保留。局部收敛标志不证明全局最优或物理参数正确。

本地`report.json`保存12400条评分的汇总；`scores.jsonl`保存逐帧漏检、额外输出、误拆／误并、条件匹配电荷／时间误差。电荷误差不是能量分辨率。两幅全波形示例在执行前固定为high_weak第0对的40和200 ns。
