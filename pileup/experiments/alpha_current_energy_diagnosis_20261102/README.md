# 当前环境短间隔能量失败的真值辅助诊断

复用L98的8对母、40条件完成160条真值辅助局部诊断；112个原拟合点的工作代价均低于真值点。修正模型8 ns的弱方向范数保留中位数25.1%，40 ns为42.9%。8 ns八次均值的弱投影由强孤立+57.43、弱孤立-4.92、共享差+11.70、背景/读出+0.18组成，单位均为100δlnE。

8 ns均值强孤立项+57.43是本批最大的带符号组均值投影，整母描述区间[+0.24, +104.63]很宽；它混合了单母光学实现、有限雪崩重复及固定模型差异，不能全归为确定模板偏差。同一8 ns条件的均值MC标准误中位数仍为44.86，40 ns为16.49。背景/读出项的组均值小，不等于全部随机噪声小：光子来源雪崩的统计涨落已包含在前三项。

这是对L98已暴露样本的事后诊断，沿用8对母、五条件、相位0；保留母未被读取，模型与参数未调整。局部量单位100δlnE，实际比较量100ln(E_fit/E_true)，均不能替代能量百分误差或盲重建指标。

## 残差与局部方向

逐重复恒等分解：观测−冻结背景−真E处联合均值 = 强孤立残差 + 弱孤立残差 + 共享减孤立的模型差 + 背景/读出残差。共享与孤立来自不同数字化，共用种子不保证同一随机实现；共享差不是无噪声因果效应。
