# 恢复历史进入 E/t 联合拟合：开发原型

本实验把共享微胞恢复的影响写入能量条件平均波形，直接重拟合沉积能量和时间。1600帧历史重放中，不含弱事件的严格整对能量恢复由53.33%升至82.33%，含弱组合38.17%→38.00%，没有净改善。保留原型与全部失败，不替换默认方法。

## 输入与条件

- 原开发库的280/280母事件分别用于本轮强度学习/检查；历史重放320母事件与两组分离。数据已有历史使用，不是新的独立确认。
- 强度用900个fold0双脉冲学习，冻结后检查900个fold1双脉冲及280单事件。
- 历史重放1200对、320单事件、80空窗；10种顺序/能量组合×8/40/200 ns，每格40对。弱/低/中/强对应源1.625/2.5/5.486/8 MeV；评价目标是实际沉积能量。
- 固定95/351 ns两发光衰减、2 ns采样、完整2.048 μs电压窗、充分动态范围、中央纯α、局部K≤2。无新ROOT、无新神经网络训练或物理配置变更。

本地输入在 `jupyter/artifacts/alpha_pair_recovery_energy_20261029/inputs/`，原路径/母事件身份在同名run_records目录的provenance.json。输入文件和本地template.npz都有SHA256；数据/二进制模型不随Git上传。

## 方法

冻结孤立能标给出q0(E)，以旧电荷守恒孤立模板计算均值，再用固定电子学AR3得到创新序列。正创新构成等效电荷活动代理，经29 ns指数记忆、14400胞归一形成邻居历史h。将创新乘exp(−a h)后反滤波为电压；不把共享分量面积重新归一至孤立电荷。唯一学习参数a=2.515148，范围[0,8]，按条件/间隔/分量均衡的分数Q残差拟合。

这是项目经验代理，不是Rosado解析式或真实微胞状态反演。29 ns沿用同系列代理参数，非6050PE实测。文献采用与限制见根目录docs/literature-use.md的L75。

四流程共同使用原NLL选出的盲K及起点：

1. 原NLL＋静态能标。
2. 只用耦合响应换算E，保持Q/t及原波形不变。
3. 孤立能量响应的E/t重拟合，a=0。
4. 恢复能量响应的E/t重拟合，a=2.515148。

两种波形重拟合使用同一固定带状权重，位于原盲Q/t处，原总电荷条件项κ=0；属于GLS消融，不是完整新似然。L-BFGS-B最多60次迭代，t在原起点±24 ns内，E限于冻结能标域。模型/参数在历史评价前冻结；推断进程拒绝truth/labels/ROOT读取，输入只有电压、盲起点和模型。

## 实际结果

严格整对成功：时间误差≤min(10 ns, Δt/4)，两事件沉积能量均在±10%，没有额外输出。含弱/不含弱各600对、15个条件/间隔，等权平均。

| 方法 | 含弱组合 | 不含弱组合 | 边界帧 | 未收敛帧 |
| --- | ---: | ---: | ---: | ---: |
| 原NLL＋静态能标 | 38.17% | 53.33% | 未复核 | 未复核 |
| 只改耦合电荷换算 | 35.00% | 75.17% | 4 | 0 |
| 孤立E/t重拟合 | 38.83% | 41.17% | 25 | 39 |
| 恢复E/t重拟合 | 38.00% | 82.33% | 0 | 35 |

恢复重拟合相对原NLL：含弱−0.17个百分点，配对95%区间[−3.00,+2.67]；不含弱+29.00个百分点，[+25.33,+32.67]。后验描述性bootstrap沿用40母事件块、两层各20、2000次，共同抽样，种子202610296701；不包含能标/模型学习或选择的不确定度。

弱组失败记账仍为117对K不符、37对严格时间不足、218对时间正确但能量不足，成功228/600。单纯修正Q→E不能解决这些问题。强/强8和40 ns由0/40变为40/40，但不能解释为普适8 ns分辨率。

原NLL/恢复重拟合的双脉冲输出均2266个，普通10 ns漏检161/160、额外27/26、严格E事件1623/1799（各2400真分量）、严格整对549/722（各1200对）。时间误拆0/0、误并100/100；同为134对计数不足。计数不足与时间图误并不是同一定义。初始scores中的split/merge为计数标志，保留原文件；audited-scores、tables/event-counts.csv明确另列原时间图标志，静态基线逐帧复现。

四方法弱单事件均65/80严格能量恢复，其余各80/80；中能单事件有1个原有额外输出，80空窗均0输出。单事件能量偏差、sigma68、E±5/10/20%、域外、漏检和额外输出均保留于表中。条件误差统计不代替全部真事件分母的效率。

## 验证与限制

- 7项数值测试通过：孤立极限、因果滤波、置换一致性、形状确有变化、无噪声电荷反演与E/t反演、空窗/能量域；旧均值和未条件化权重的兼容性检查通过。
- 留出900对的分量Q相对RMSE：含弱组合7.05%→3.06%，不含弱组合8.84%→1.78%。含弱组统计两个分量，不是只统计弱分量。
- 280单事件在零邻居下严格不变。1180个实际响应的支撑外因果性、有限性、面积、非负性到浮点精度均核对。
- **名义起点因果性断言未通过**：冻结旧模板在t前0.25 ns有插值支撑，最大提前修正0.000129 mV；实际模板支撑前的影响为零。没有事后改模型/预测，原失败记录和报告v1保留，v2只修订报告检查并显式保留此限制。不能声称严格连续时间物理因果性。
- 6帧先导的两进程成本估计307.34秒，余1594帧实际325.52秒。35帧恢复重拟合未收敛，仍纳入全部评价；不宣称全局最优。
- 本轮固定原盲选K，不能恢复被原门漏掉的事件。并非新独立输运确认，也不验证γ、free-τ、高率K≥3、位置/参数失配或实物性能。
