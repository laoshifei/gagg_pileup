## 输入与方法

已有8个光学母事件，源能量1.625/8 MeV，评价采用实际沉积能量。4组固定母对，孤立弱/强、强→弱8/40/200ns、弱→强40ns；每组16个独立参考数字化，另8次评价。沿用95/351ns双发光衰减、14400微胞/29ns代理、固定恢复强度和能标。合并光子后共享微胞，0.1mV电子学噪声；4.096us数字化、2.048us观测，模拟电压不作ADC触顶拒绝。未生成G4/ROOT/宏；母ROOT身份和缓存光子哈希、原配置元数据已记录。

原计划16＋16的保守成本3397s超过1800s，执行计划按时间缩为16＋8，估算1763s；原计划/失败检查/源码保留，实际两进程464.66s。冻结源代码在source（原版）和source-v2（实际执行），仅改变样本数/运行器，未修改物理或搜索。另有8次先导不计入正式结果。

三域为真实重复、独立参考均值替换、匹配高斯。均值替换使用真E/t，不可部署；有限16次参考误差保留并在评价间共享。高斯精确匹配FIR域协方差，电压噪声前缀置零，不等价于真实探测器噪声。两权重保留相同边际方差，对角版本只删除相关性。固定K/t六起点能量拟合不接收真E/Q。

## 得到的证据

强→弱8/40ns的均值替换降低弱E偏差和RMSE，严格成功仍2/32、5/32；匹配高斯也未解决这些条件。弱→强高斯32/32过于乐观：原权重主起点约165ns、漏掉128ns弱脉冲，132–164ns实测方差为原预测3.58–5.29倍。事后使用真K/t/E构造双分量协方差，其局部弱lnE尺度约0.122–0.127，相应实测投影0.103–0.124；原模型只有0.0035–0.0039。这是机制检查，没有改变任何拟合或证明新盲效率。

均值差异还分解为孤立母波形（幅度＋形状）差异和新增相互作用差异，恒等式通过；后者不能代表全部误差。固定光子重复不含新的输运涨落，只有4母对，有限搜索不证明全局最优或物理分辨极限。
