# 面积保持的条件均值修正

面积保持的条件均值修正未通过孤立阶段推进门，失败项：weak projection gap8。四档孤立能标、相位和RMSE门通过，组平均波形残差MSE比（修正/旧）依弱/低/中/强为0.851、0.950、0.310、0.954，但沿固定旧弱能量方向的平均投影8 ns由-4.83变为-29.05；40 ns由+1.71变为-4.79，单位100δlnE。

| 名义弱间隔 | 旧平均及95%区间 | 修正平均及95%区间 | 绝对均值限值 | 通过 |
| --- | --- | --- | --- | --- |
| 8 ns | -4.83 [-53.18, 40.25] | -29.05 [-77.42, 16.02] | 10.00 | 否 |
| 40 ns | +1.71 [-12.97, 15.84] | -4.79 [-19.48, 9.34] | 10.00 | 是 |
| 200 ns | +7.96 [1.12, 14.40] | +0.95 [-5.90, 7.39] | 10.00 | 是 |

按冻结协议停在孤立门，没有运行共享/孤立双脉冲数字化、双脉冲能量拟合或更换默认重建。预先保存的80个双脉冲任务只是计划，不能计为已运行。数值上共享减孤立项保持一致，并不能代替实测共享响应的迁移验证。

训练128个历史母事件，评价64个不同历史母事件，四个源能区、四个采样相位。训练1024、评价2048、先导4、重放4，共3080次离线数字化；正式4608、先导36次孤立能量拟合。没有新ROOT。源能量与真实E_dep在mothers.json中分开记录，原ROOT的实际宏/种子保存在original-metadata/、original-runinfo/。

q0(E)、返回Q(E)与共享减孤立项保持；新形状为训练残差的固定面积投影和log q0插值，不是逐事件自由形状参数。真实E只用于训练/评分，拟合只读电压和冻结模型，K=1/时刻已知。全波形残差MSE降低仍不保证弱方向改善。投影单位100δlnE，不是实际双脉冲能量误差。

评价集仅64个已暴露历史母事件，强档16母；重复和四相位不增加独立输运数。训练128母也曾参与旧均值/空间先验。本轮按母隔离只约束新增修正，不能称全新确认。均值波形仍含有限数字化涨落。固定95/351 ns、快比例0.3、29 ns恢复代理、14400微胞、12×12空间先验和2 ns采样；未传播器件、能标、原模型及新均值训练误差。组均值通过不能保证每母无偏；误差SD不是单能峰实测FWHM。已知K=1和时刻，未测盲漏检、误拆分、误合并、能谱选择效率或高率性能。

下一步先检查条件均值在不同光学母事件划分中的稳定性与训练不确定度，用开发母事件的分组交叉验证同时考察全波形和固定弱能量敏感方向；冻结后再作未参与调参的母事件确认。当前评价结果不可用于反复选择平滑宽度、修正幅度或方向。若主要误差来自母间涨落，应增加独立母事件而非只堆同母重复；通过孤立与共享门后再做同输入、同权重和搜索预算的双脉冲能量比较。
