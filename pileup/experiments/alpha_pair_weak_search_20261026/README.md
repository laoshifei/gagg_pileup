# 弱分量搜索与局部时间—电荷剖面

本轮针对先强α后弱α的恢复失败，保持已冻结的面积守恒均值、联合协方差、logdet、95/351 ns双τ及完整2.048 μs模拟电压，检查候选搜索。旧联合似然的开发批和之后已公开的确认批各1600帧，在本轮都属于开发资料；旧独立结果原样保留，不重新称本轮优化为独立验证。

## 预先固定的设计

280个原生单事件母样本只用于门槛标定，与均值／噪声训练280个母样本、较早开发批320个母样本、最新公开批320个母样本四组互不交叉。每个评价批含十种双事件组合×8/40/200 ns×40对、80空窗及320原生单事件；同一母样本会被不同条件复用，不累计独立曝光。

每种新搜索共3480帧。`legacy_extra`采用原来的15%/50%/85%电荷分配，`weak_extra`额外加入1%/3%/5%/10%及对称分配。保持4/8/12/20/40/80/160/320 ns的候选间隔，两种方向都考虑；每个间隔／方向先取初始NLL最好的份额，再从每方向取四个起点。两种方法都至多8次20迭代筛选、2次70迭代精修，并保留原最佳双事件候选。新方案初始代价计算更多，但额外非线性优化预算相同；运行时间为缓存原搜索之后的增量，不能冒充总耗时。

原K=0/1候选、模型和原始检出保护条件均保持。推断worker仅收到电压及由同一电压生成的旧候选，禁止读取ROOT、truth和case文件。扩大搜索后，两种方法各自在同280个原生单事件上重新标定增峰门槛；保持加一／并列上尾秩p≤0.025、拟合Q分档1500/5000/12500 pe。Q是实现雪崩等效电荷，t是有效SiPM面首光子；不把Q精度写成沉积能量分辨率。

整对成功要求两真实Q≥500 pe、各Q误差≤20%、各t误差≤min(10 ns,间隔/4)、无额外输出。全部漏检、额外输出、误拆／误并和匹配Q/t误差保留。

## 真值辅助诊断

对最新公开批全部high_weak和weak_high各120对，进行固定真实时刻的Q拟合、真实Q/t初始化的局部联合拟合。另预定high_weak每间隔的前两对，共六个时间—电荷图：弱事件时间相对真值−48至+48 ns共13点，Q为真值的0.25至3倍共9点；每点固定弱Q/t，重新优化强Q/t，使用真实及原单事件拟合两个起点。强事件时间限于真值±48 ns。这些真值输入只用于诊断，不能算盲恢复或全局分辨界限。

40 ns第0对额外细化至25×17点，核对共用网格点和最低值。图中的ΔNLL仅是代价差，不使用Wilks近似标注置信区间。噪声数据拟合后的代价低于真值点本身正常，不能单凭这一点断言模型有偏。

## 选择与验证

所有规则在新结果产生前写入`protocol.json`。进入新母事件确认需最新批high_weak、40 ns提高至少10个百分点（40对时为4对）；两批high_weak、200 ns均不得低于原联合似然，较早批40 ns不得退步。两批weak_high、8 ns最多下降5个百分点；弱组合平均不得下降，较强组合平均最多下降2个百分点。每组空／单额外输出≤5%，各单成功≥95%，匹配Q偏差中位绝对值≤5%。这些是开发选择条件，不是总体误报或统计显著性保证。

配对区间按每批40个母事件块重抽，前20／后20块分层，各条件、间隔和方法共享权重，2000次、种子276990226；它们仍是开发描述性区间。达到要求的候选才冻结并另取新母样本确认。

初始7项数值测试通过；两种74帧小样本和两个真值辅助诊断通过，随后执行完整计算。所有输入哈希、母事件划分和实际运行环境保存在本地`jupyter/run_records/alpha_pair_weak_search_20261026/`；结果保存在同名`jupyter/artifacts/`目录。`freeze.json`记录实际分析源码、旧物理源码、模型、协议和运行器，不静默改写历史实验。

文献仅复用Fixsen等2004的条件均值／协方差思路（DOI 10.1016/j.nima.2003.11.313，PDF2式1–2、PDF3；TES模拟每能量5000次，既有AI笔记待人工审核）。本轮剖面和搜索方案为项目实现，该文没有给出对应GAGG逐事件恢复性能。本轮未修改共享文献库。
