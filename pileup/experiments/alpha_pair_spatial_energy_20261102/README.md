# 空间恢复模型的已知 K/t 能量拟合先导

本实验接续 `alpha_pair_spatial_recovery_20261102` 的响应检查，检验面积预测改善能否转化为沉积能量恢复。原空间模型、孤立标定、噪声参数及默认盲算法保持原样。本轮给定真实脉冲数和到达时间，仅拟合未知的 E_dep（MeV）。

## 冻结输入与比较

使用上一轮16个历史评价母事件，与128个空间先验开发母和全部560个旧均值/噪声开发母不重叠，但已经用于响应诊断，不是新的独立确认。孤立控制为16母各8次数字化，并另拟合各母的8次平均波形。共享控制用其中4对强弱母事件，五条件为强→弱8/40/200/1200 ns、弱→强40 ns。

上一轮共享输出只保存祖先分量，不能直接作为完整含噪输入。本轮沿用原光子及 `715100000+block×1000+repeat` 种子，重新生成160次4096 ns共享数字化，加入该实现的暗信号和电子学噪声；读出种子为雪崩种子加10,000,000。所有事件祖先分量/电荷必须与旧数组逐项一致。拟合窗口固定为前2048 ns、1024个完整模拟电压样点。孤立128条波形直接复用，没有重新数字化。没有新ROOT或Poisson注入率。

预先固定拟合20条8次平均的双脉冲波形，以及每条件/母对前两次的40条单次含噪波形。后者每条件只有8条、4个光学母对；不是8个独立输运样本。无噪声空间模型先导每拟合约96秒，因此先完成这一小样本阶段。样本数在看物理能量拟合结果前冻结，本轮不根据结果扩样；平均波形与单次子集的重复构成不同，不把两者差异解释为纯粹的噪声因果效应。

主比较是均匀微胞与12×12空间恢复响应（均1 ns），空间先验、恢复强度、微胞数、95/351 ns光形及各自电荷反演表均继承前一实验，没有重新调参。一次权重由共同电压的孤立NNLS初值和既有噪声标定构造，两模型的权重、初值和三个搜索起点严格相同；权重不是新校准的空间模型似然。

两个能量使用相同对数边界 `[0.1183134541, 8.6611928940] MeV`、相同三个起点（NNLS及等效电荷占比0.1/0.9）、相同解析梯度和每起点80次函数评估预算。比较的是有限搜索结果，不证明全局最优。孤立拟合采用相同的一维有界求解，其输出必须逐项一致，并复现上一轮同相位的均值能量。完整求解设置见 `protocol.json`。

拟合工作进程仅接收电压文件、真实K/t和行标识；没有真实能量、光子落点、祖先波形或分量电荷。运行时审计拒绝读取标签、光子及诊断目录。真值只用于数字化、数值反演控制和独立评分。

## 端点与推进条件

逐条件报告两分量的相对能量偏差、相对误差SD、RMSE、两能量均在±10%且收敛的严格整对成功数、边界数与未收敛数。SD混合本批母事件和重复波形的涨落，不称真实器件能谱FWHM。所有失败保留在分母。K/t已给定，因此本轮没有盲漏检、误拆分、误合并或能谱选择效率测量，相关值不填零。

配对描述性区间用10,000次母事件块重采样；单次端点同时在每母内重采样两次重复，模型间保持配对。均值端点只重采样四母对。区间条件于冻结先验和噪声参数，不传播128母先验估计及器件系统误差。

先通过数值梯度/模型内能量反演和孤立组均值±5%门。下一阶段独立确认的建议门预先定为：强→弱8/40 ns合并严格成功提升至少10个百分点，合并弱能量RMSE比≤0.95，两间隔分别RMSE比≤1.1，两间隔平均波形的弱能量偏差均≤10%。这些是本项目推进门，不是显著性门或文献性能保证；本轮无论结果如何都不直接替换默认算法。
