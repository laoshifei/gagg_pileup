# 全候选能量协方差比较（2026-10-30）

预先主方案“能量协方差/一次”没有带来一致的严格恢复收益：弱→强40 ns为17/32→18/32（改善2、退化1），强→弱40 ns为5/32→1/32（改善0、退化4），8/200 ns分别保持2/32、6/32。全候选旧形状、能量一次及FGLS在各条件的严格成功数相同，但不表示每条能量估计完全相同；继续迭代权重未增加成功数。NLL也没有一致改善，且孤立弱控制29/32→28/32。

## 设计与输入

第43节发现原协方差遗漏早到弱脉冲，本轮实现不读取逐事件真实E/Q的修正，并检验它是否真正改善沉积能量恢复。**仍给定真实事件数K及固定真实到达时间t，只有能量未知**；这是纯α机制诊断，尚未验证盲检出或α/γ分类。

复用上一轮24组条件中的192条物理数字化评价波形（4光学母对×6条件×8重复），保持原噪声、源母文件、随机种子和完整观测窗不变。另用真实参数及新的能量协方差生成192条独立种子高斯控制；它们是新模型抽样，不是新输运或新探测器观测。高斯控制在FIR域精确匹配、首3个电压噪声样点置零，不能与旧协方差下的高斯32/32当作配对增益。

均值仍为95/351 ns双衰减对应的冻结响应，恢复强度2.515148098、能标、29 ns恢复代理及14400微胞保持。1024×2 ns观测窗、采样中心0.25+2n ns、首次有效光子128 ns，沿用足够动态范围的完整模拟电压。无新ROOT、宏、G4或训练。真实物理输入源窗4.096 μs，本轮只重拟合既有观测窗。

| 方法 | 权重/目标 | 数据与搜索 |
| --- | --- | --- |
| 原固定GLS | 独立16次参考平均电压的一脉冲协方差 | 精确重放旧算法；线性＋5份额起点 |
| 全候选/旧形状 | 由原拟合E预测共享Q，再把全部已知时刻放入旧Q条件形状协方差 | 一次冻结权重；主要检查候选覆盖 |
| 能量协方差/一次（预先指定主方案） | 直接用原拟合E的恢复响应分量及预测共享Q构造C | 一次冻结；旧E＋线性＋5份额起点 |
| 能量协方差/FGLS | 内层固定C拟合E，外层由新E重建C | 最多4次权重更新；后续用前次解启动；max|ΔlnE|≤0.001为稳定标志 |
| 能量协方差/NLL | 均值与C同时取当前候选E；目标含二次型和logdet | 旧E、线性、5份额及一次权重解启动；每起点最多120次迭代 |

全部噪声系数、相关项及指数限幅沿用旧标定，κ=0，不根据这批真值重新学习。把旧经验协方差用于恢复后的能量均值，是本项目待验证的假设；不是已经完成能量条件噪声标定。

记r为观测减均值后的FIR残差，NLL使用

$$J(E)=r(E)^\mathsf{T}C(E)^{-1}r(E)+\log\det C(E).$$

共同常数n log(2π)省略。固定C的GLS与该完整高斯目标分开；各个固定权重下的cost不能跨方法直接比较。FGLS也不保证每步降低同一个NLL或找到全局最优。边界沿用冻结能标支持域。

拟合进程只读电压、已给定的时刻、原观测参考权重与初值；禁止打开事件能量标签、旧结果及ROOT。真实E用于高斯生成和独立评分，不用于实际波形的权重构造。原权重仍依赖同光学母事件的16次独立参考重复；本轮整体不是直接可部署的单条未知事件流程。

方法及输入在新高斯生成/拟合前冻结。先导只估成本：4进程保守估算2294.79秒超过1800秒，于是仅改6进程、BLAS单线程，估算1529.86秒。原计划、失败先导、source及source-v2分别保留；未改样本、种子、方法、起点或精度门槛。

原单脉冲模型早期实测/预测方差为3.58–5.29，能量/一次变为0.64–0.83，表明前沿遗漏项已经补入，但本批预测方差仍高于重复测得值，尚非准确标定。各母组只有8次重复，且预测能量来自同批波形；不能把比值变化视为统计显著性或完整协方差验证。新高斯的弱→强40 ns在原GLS/一次权重/NLL下为18/32、23/32、24/32；物理波形为17/32、18/32、17/32。模型内改善没有等量迁移到物理重复，提示继续检查均值、条件噪声及固定光学母实现差异；它本身不能唯一确定误差来源。

弱→强40 ns的弱E偏差均值由+2.61%变为+1.48%，RMSE由17.20%变为13.48%；这是该固定母组设计上的误差改善。强→弱40 ns的偏差+44.92%→+40.22%、RMSE74.71%→69.37%，严格成功却5/32→1/32，说明均方误差改善与落入±10%区间的数量并不等价。强→弱8 ns的偏差+93.28%→+74.77%，RMSE反而160.59%→162.14%，边界解7/32→9/32；不能只报偏差下降。这里的比较为原GLS→能量/一次，均包含全部重复。

当前修正保留为研究对照，不替换默认盲算法。下一步优先用独立母事件标定并验证能量条件均值与噪声，包括分量能量方向的相关性，而不只看早期边际方差；旧噪声系数迁移到恢复均值仍缺这种验证。随后与前一轮文献调研提出的恢复反演/反卷积基线按同一物理输入、同一能量端点比较。原生单/双控制与独立母事件通过后再扩未知K/t、α/γ四种组合及完整计数率窗口。新模型高斯在强→弱8/40 ns也没有良好的±10%恢复，说明本设定下仅改权重仍不够；这不是普适不可辨识界或任何算法都不能恢复的证明。
