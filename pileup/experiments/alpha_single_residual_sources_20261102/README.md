# 强孤立残差来源与可预测性诊断

本实验完成64个历史光学母事件的1024次重复数字化，区分平均模板误差、母间差异和母内数字化涨落，并在母事件不重叠的保留数据上测试观测电压前段对稳定强孤立残差的预测。已知K=1和时刻，目标用真实E/祖先信号构造；预测特征只读电压。没有新G4/ROOT或盲恢复结果。

强孤立残差沿8/40 ns弱能量方向的平均投影为+41.65/+24.92（单位100δlnE），母事件重采样95%区间均在零以上。按B/(B+W/8)估计，8次数字化平均时母间差异仍占投影方差的70.16%/85.43%。这同时支持存在平均响应偏差和不能靠同母重复平均消除的差异；B还可能包含未去净的能量趋势/几何效应，不能全部归为纯光子统计。

8/40 ns可用前段中，加入四个形状特征相对仅电压能量代理的MSE比为0.9942/0.9751，相对训练均值基线的配对95%区间均跨1；两项主要条件均未通过事先冻结的推进门。没有证据据此增加逐事件形状自由度或替换默认重建，也没有证明其他特征/非线性模型必然无效。

```bash
python3 -B pileup/experiments/alpha_single_residual_sources_20261102/run.py verify
```
