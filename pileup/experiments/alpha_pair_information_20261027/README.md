# 双事件恢复阶段与局部信息诊断

2026-10-27执行。承接`alpha_pair_model_closure_20261026`，把输出两个脉冲、定位两个时刻与估准两个电荷分开，并量化强弱参数之间的耦合。结果是诊断，不更换默认算法。

## 输入与条件

复用760帧已公开原生数据、1520帧匹配高斯评价数据，以及已有盲拟合和真值辅助拟合。双事件分别360、720帧；原生360个参数点为中／中、先强后弱、先弱后强×8/40/200 ns×40对。高斯两次噪声抽样不增加光学母事件；不同条件和间隔复用母样本。没有新ROOT、训练或波形拟合。

保持纯α、固定95/351 ns发光双τ、2 ns×1024点完整模拟电压、充分动态范围和局部K≤2。原生Q为实现雪崩等效pe，高斯Q为数值相同的条件参数，均不能当作沉积能量；t为有效SiPM面首光子。继承固定FIR的1021维边缘分布和前三点边界处理。

## 计算与实际结果

四层评分以全部双事件为分母：输出K=2；两个时刻误差≤10 ns；两个时刻误差≤min(10 ns,Δt/4)；再要求各Q误差≤20%且无额外输出。K=2本身不代表检出了正确的弱事件。

| 先强后弱，40 ns | 输出K=2 | 两时刻严格正确 | 两Q/t严格正确 |
| --- | ---: | ---: | ---: |
| 原生40对 | 7 | 2 | 0 |
| 匹配高斯80对 | 9 | 4 | 0 |

在真实参数处、已知K=2时计算完整高斯期望信息：`Fij = mu_i.T C^-1 mu_j + tr(C^-1 C_i C^-1 C_j)/2`。坐标为`t1/(10ns),t2/(10ns),ln(Q1/pe),ln(Q2/pe)`；含协方差导数。弱参数未知时取完整逆矩阵子块；已知其他参数时先取信息子块再求逆。没有伪逆或岭正则。

| 40 ns条件，中位局部尺度 | 全部未知 | 两时刻已知 | 强Q/t已知 |
| --- | ---: | ---: | ---: |
| 先强后弱，弱lnQ | 0.47785 | 0.47425 | 0.04871 |
| 先弱后强，弱lnQ | 0.08294 | 0.08195 | 0.04090 |

先强后弱的弱t尺度中位3.643 ns，强弱Q局部相关系数−0.99480。探索性分拆得到：只固定强Q时弱lnQ尺度0.04871，只固定强t为0.47509。固定强参数仍保留强事件随机噪声，不等于减去真实强波形。这支持当前模型内电荷分配歧义的作用，但不提供可盲取得的强Q。

444点包括360个原生参数点，80个名义设计点，以及4个相位点。名义设计固定强Q=18000 pe，弱Q=500/700/1500/3000 pe，间隔2/4/8/12/20/40/80/120/200/400 ns，两种顺序，首时刻160.37 ns。四相位检查仅在强→弱40 ns、18000/700 pe进行，弱lnQ尺度范围0.43765–0.43916，弱t尺度3.105–3.792 ns。网格是条件模型的局部信息，不能把曲线与20%容差尺度的交点称为分辨极限。

另将原生240对和高斯480对的已有K=2／真实初始化／固定真实时刻拟合误差归一化，共2160条，全部失败和未收敛结果保留。40 ns高斯先强后弱的已有K=2候选22/80位于二维局部95%参照区域，真实初始化74/80；后者严格成功仍24/80。固定时刻73/80在一维参照区域，严格成功29/80。较宽区域内不等于满足Q±20%。

固定时刻的弱Q相对误差16/50/84%分位，高斯−46.0%／+10.4%／+59.9%，原生−24.3%／+21.5%／+43.1%。原生偏差、有限搜索和非线性效应仍需处理。真实初始化直接使用Q/t并限制时刻在真值±48 ns，其误差集中不代表突破理论下界。

## 验证和局限

6项数值测试覆盖解析高斯例子、协方差迹公式、坐标缩放、140000次有限似然差分score抽样、Schur补／干扰参数、固定协方差GLS及带状降秩展开。三个先导点通过后使用4进程；正式441个新增点约367秒。源版本为`bcb27007fadf5df7dbb1d2447638b1f371069a8c`加冻结清单所列本轮新增源码。

中心差分初始步长0.001，主步长0.0005，必要时减至0.00025／0.000125；分别426／9／9点使用后三个步长，444点均通过预定≤2%矩阵与尺度变化要求。最大矩阵变化0.1582%，最大尺度变化1.9592%；白化相对误差≤1.32×10⁻¹⁵，最大信息条件数约1.75×10⁶。无未解决点，无选择性删除。1080条分层严格评分与原缓存逐条一致，原2280帧主比较和2160条辅助拟合均保持。

逆信息仅作局部正则、正确模型和适当无偏性等条件下的参照，不是有限拟合实际标准差或置信区间。较大的lnQ尺度不能直接转写成相同数值的相对电荷标准差。经验插值、边界、非高斯性、已知K、真实参数条件及母样本复用均限制解释；没有验证free-τ、混合α/γ、随机高率K≥3或实物性能。

文献采用Liddick2012的检测／估计分开评价、Fixsen2004的条件均值／协方差；两篇既有AI精读稿待人工审核，本轮没有重查PDF。Fisher公式及GAGG计算为本项目推导和实现。采用位置、适用条件和待办见`docs/literature-use.md` L59。
