# 弱能量残差投影、权重与搜索诊断

复用20条8次平均波形，完成120组线性投影与88条正式非线性对照。40条真实E起点对照中，0条找到超过预设数值容差的更低代价，最大能量变化0.00179%；这项对照未支持原搜索起点是本批主要偏差来源，也不证明全局最优。空间模型精确删除强脉冲孤立响应残差后，8 ns弱E偏差+21.57%→-6.57%，RMSE 56.57%→9.39%；40 ns弱E偏差+41.48%→-0.28%，RMSE 50.50%→3.19%。删除使用真实E和祖先分量，只用于误差诊断。

## 冻结方案

沿用上一阶段的原始电压、空间先验、孤立均值能标、各自Q→光量映射及噪声标定，不重新数字化。观测窗0–2048 ns、2 ns采样，保留完整1024点；真实时间为128 ns及128+间隔。输入路径与原种子映射见cases.json、input-freeze.json和父实验。

令A为真E处孤立模型，M为真E处共享模型之和，I/S为物理孤立/共享祖先信号，Y为完整含噪电压、b为固定背景。四项为I强−A强、I弱−A弱、(ΣS−ΣI)−(M−ΣA)、Y−b−ΣS；逐重复严格相加为Y−b−M。末项含背景期望失配，不只是一份白噪声。

θ=ln E，J=W·T·∂M/∂θ；用SVD计算δθ=J⁺W·T·r。T是继承的FIR变换，W固定在原完整平均波形的电压初值上。强/弱导数耦合被共同求解，也单独核对消去强导数后的弱方向。原始电压影响函数用于累计时间图，避免把白化后的索引误称为局部物理时间贡献。各项只在线性δlnE中可加；exp(δlnE)−1用于总变化，不能分别指数化再相加。另给出真实能量边界下的线性有界解。

三种固定权重为原full、只保留边际方差的diagonal及unit FIR；后者不是原始电压OLS。40条full真E单起点、16条空间短间隔权重三起点、32条空间短间隔单项删除真E起点，共88条。继承logE边界[0.1183134541,8.6611928940] MeV、每起点80次评估及原求解容差。比较权重时仍使用原三个电压起点；删除项时权重固定为原波形full、起点固定为真E，与同起点原波形对照。不同权重的代价绝对值不横向排名；非线性删除效果不相加。

## 限制与下一步

仅四个已暴露历史母对，五个条件，每条均值由8次数字化组成；重复不增加独立输运样本，均值不是无噪声理论期望。强/弱孤立残差同时包含固定光学母事件实现的差异和有限数字化涨落，不能全部归为普遍模板系统偏差。共享与孤立数字化的随机数消耗不同，四项互相关，删除后的波形是人工构造，不能把其收益当作可实现算法效率。真值投影、真值起点和残差删除均标为oracle；权重对照仍给定真实K/t。未测盲漏检、误拆分、误合并、能谱选择效率或高率性能。固定95/351 ns、快比例0.3、29 ns恢复代理、14400微胞和12×12开发先验；未传播先验、能标及器件系统误差。

下一步优先利用原有开发母事件研究强脉冲孤立形状的逐事件变化及其与能量的关联，在独立开发划分上冻结低维形状/噪声处理方案，再用孤立与受控强弱双脉冲检查它是否吸收真实弱信号。固定权重对照须作为完整候选方案验证，不按本批每个母事件或间隔选择最优权重。本轮不调整恢复强度、不升级默认重建、不增加独立输运；后续改变模型或权重时另建实验快照。
