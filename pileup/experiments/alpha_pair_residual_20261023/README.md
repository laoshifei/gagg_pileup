# 相关权重正则化与残差新增事件候选

本轮继续处理低Q的GLS电荷偏差和强脉冲后弱脉冲漏检。纯α、固定95/351 ns双τ、2 ns采样、2.048 μs局部完整模拟电压、已知基线、充分动态范围；Q是实际雪崩等效pe，不是源能量或沉积能量。

## 方法与开发边界

均值响应和两个网络权重沿用 `alpha_pair_conditional_20261022`。原响应的训练母样本用于小规模权重／搜索试验；上一轮已公开的240个测试母ROOT明确改作本轮开发数据，取每条件／间隔前20对及全部80空窗、240单事件，共1320帧。两批母样本分离。本轮没有重训网络。

先检查GLS与OLS精度混合、AR相关系数缩减；完整开发比较原ρ≈0.9783、0.9、0.8。每帧平滑观测先验固定，各K/t/Q候选共用同一协方差；这是经验GLS正则化，不是测得的新器件参数或精确似然。零模型代价缩放至约10⁶以保持优化数值尺度，K选择再除以该代价；初次104帧探查使用单位缩放，后续搜索及正式推断使用10⁶缩放，早期结果单独保留。

单事件拟合后，在残差上扫描固定线性字典，先投影掉已有脉冲的局部Q／t切向。至多4个残差峰及4个离散间隔／电荷分配候选进入非线性联合拟合，后者使用原条件响应。新增起点先最多20次函数评估，最好的两个再最多60次精修；数值Jacobian调用另计。局部半径24 ns，K仍限制0/1/2；未知K由归一残差加每事件惩罚决定。波形候选和网络候选分别保存，网络输出数不作为强制限制。

开发选择同时要求各空／单控制额外输出≤5%、各单事件成功≥95%、各单事件电荷相对误差中位绝对值≤5%；在合格方案中提高五种组合等权的整对成功率。候选搜索与权重分别作消融。旧流程与新流程的搜索半径／起点预算不同，跨轮结果是整个流程比较，不能全部归于ρ变化。

方法依据复用Fixsen2004（TES条件均值／非平稳权重）和Zhang2024（LaBr₃幅度相关模板／残差增峰）的已有精读记录，均保持AI待审；本轮没有重读PDF或修改文献库。ρ缩减、切向投影和具体门槛为项目实现，不是论文给出的GAGG性能结论。出处和采用边界记录在 `docs/literature-use.md` 的L51。

## 新独立检验

本文t为进入SiPM有效面的首光子时刻，Δ为这两个时刻之差；不是源发射时刻或峰顶间隔。原波形检测器只给零模型的帧跳过增峰；同K网络对照没有可用同K精修时保留原网络输出。这项预筛对阈附近事件的漏检仍待检验。

开发选择完成后冻结全部源码、响应、权重、配置和阈值，另生成源2.5／5.486／8 MeV中央入射单α母ROOT各80个。每ROOT一个20 μs WaveformEvent，G4内部串行，最多4个进程、启动至少间隔1秒。双事件由新光子共同数字化，使用4.096 μs离线窗、分析前2.048 μs；不缩放光子、不叠加独立电压。单事件保留原生电压。

五组组合、4/8/12/20/30/40/60/80/120/200 ns，每点40对，另有80空窗及240单事件，共2320帧；跨点复用母样本，不能当作2320次独立曝光。整对成功要求两个真Q≥500 pe，各Q误差≤20%，各t误差≤min(10 ns,Δ/4)，一对一恢复且无额外输出。匹配条件下的电荷误差、漏配、额外输出、误拆／误并及空／单控制同时保留。逐点Wilson区间不是全曲线保证。
