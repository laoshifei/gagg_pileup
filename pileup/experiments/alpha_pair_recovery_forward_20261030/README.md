# 原电压前向接口：未通过物理因果控制

这版原电压前向接口未通过物理控制，不替换既有方法。32对双脉冲严格E_dep±10%成功数为：既有GLS 9/32、上一轮RL＋恢复4/32、原电压OLS 2/32、原电压GLS 0/32、补均值校准后的主方案0/32。不能由此评价GLS本身的普适优劣，更不能解释成这些间隔的堆积物理上无解。

在真实E/t处作事后诊断，强单脉冲原电压模型的事件前预测峰值均值为27.44 mV，校准后仍3.55 mV；电子学噪声RMS为0.1 mV。对应事件前白化残差平方占整个窗口的逐帧比例均值约94.32%→42.04%，既有GLS均值对照约11.72%。诊断只统计采样孔径整体在事件前的点，即ADC中心+0.25 ns≤t0，排除孔径跨过事件起点的合理响应。

上一轮光时序模板描述的是带有限迭代模糊和噪声的反卷积输出，其−64 ns起的支撑并不是物理入射光的因果支撑。把这种均值直接送入恢复模型返卷，会在真正事件前产生假信号；此处主要是背景噪声，GLS对模型误差的惩罚很大，因而可能压低正确事件的能量并把能量分给后续事件。该检查定位到适配中的具体缺陷，但未证明它是全部误差的唯一来源；均匀照明、2 ns箱内相位近似、平均场串扰及移植的协方差也仍需检验。

本轮沿用Bretz等（2020）预印本[10.48550/arXiv.2010.14886](https://doi.org/10.48550/arXiv.2010.14886)的反卷积/恢复校正结构，其原文§5.1式5.8/5.12并没有证明本项目这套“平均反卷积结果再作为物理光模板”的转接成立。原论文的S13360-6025PE、总光子数目标和高信号条件与本项目逐事件α能量分解不同；本轮不是作者MC复现，也没有新增文献入库或审核状态修改。
